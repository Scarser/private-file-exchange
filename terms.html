Private File Exchange

Условия использования

Дата редакции: 17 ноября 2026 года

1. Доступ к приложению

Private File Exchange предназначено для небольшой группы приглашённых пользователей. Каждый Google-аккаунт подключается с согласия его владельца. Приложение можно использовать только для файлов, с которыми пользователь вправе работать, и в пределах выданных ему разрешений.

2. Операции с файлами

Пользователь определяет, какие файлы обрабатывать, куда их сохранять и кому передавать. Перед изменением, перемещением или удалением важных данных следует проверить задание и сохранить необходимую резервную копию. Настройки доступа Google Drive продолжают применяться при использовании приложения.

3. Доступность и отключение

Работа приложения зависит от доступности Google API, сети и локального компьютера. Операции могут завершаться ошибкой или требовать повторной авторизации. Пользователь может прекратить использование приложения и отозвать его доступ в настройках Google-аккаунта.

4. Обработка данных и контакт

Порядок работы с данными описан в Политике конфиденциальности Private File Exchange. Вопросы об использовании приложения и доступе принимаются по адресу professor1994@gmail.com.
